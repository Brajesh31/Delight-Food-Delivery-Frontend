# Support

For setup, UI, or documentation questions, open a GitHub Issue with clear reproduction details.

Before opening an issue:
1. Read README.md and the relevant guide under docs/.
2. Check for an existing issue describing the same problem.
3. Confirm the issue occurs on the current main branch.
4. Run npm ci, the tests, and npm run build when relevant.

For a bug report, include browser and version, operating system if relevant, viewport dimensions, route, reproduction steps, expected and actual behavior, and a screenshot with private information removed.

Do not include passwords, payment details, real customer addresses, or private credentials. Report sensitive vulnerabilities according to SECURITY.md.

This repository is a frontend demonstration. It does not provide live restaurant support, real order processing, payments, or delivery tracking.
