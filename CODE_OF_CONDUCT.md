# Code of Conduct

## Commitment
The project aims to provide a respectful and constructive environment for contributors at different experience levels.

## Expected behavior
- Be respectful, patient, and professional.
- Focus criticism on code and ideas, not people.
- Explain disagreements with evidence and practical reasoning.
- Accept constructive feedback.
- Respect privacy and intellectual property.
- Keep discussions relevant and useful.

## Unacceptable behavior
- Harassment, discrimination, threats, intimidation, or personal attacks.
- Publishing private information without consent.
- Spam, deliberate disruption, or repeated bad-faith conduct.
- Pressuring contributors to share passwords, personal data, or private contact details.
- Misrepresenting project capabilities or using the project to deceive users.

## Reporting
Report conduct concerns privately to the repository owner through GitHub. Avoid posting sensitive personal details in public issues. Include relevant context or links where safe.

## Maintainer response
Maintainers may edit or remove harmful content, close discussions, or restrict participation when necessary to protect contributors and maintain a constructive project space.

## Scope
This policy applies to repository issues, pull requests, code reviews, and project-related spaces where participants represent the project.
